## Control size

You can control the icon size with the `width` and `height` props.

- Pass numbers directly, or strings with units such as 'px', 'rem', or '%'.
  - (The icon keeps its intrinsic aspect ratio and cannot be stretched.)
- The default `width` is '1.5rem'.
- The default `height` is '1.5rem'.

<SizePropsCompareList icon={'valet'} sizes={['1.5rem', 30, '48px', '5rem']} />

```tsx
<CarmoreIcon icon={'valet'} ... /> // Uses the default ('주차 대행')
<CarmoreIcon icon={'valet'} width={30} height={30} ... />
<CarmoreIcon icon={'valet'} width={'48px'} height={'48px'} ... />
<CarmoreIcon icon={'valet'} width={'5rem'} height={'5rem'} ... />
```

## Accessibility (a11y)

We recommend setting accessibility attributes such as `role` and `aria-label`.

- The default `role` is 'img'.
- The default `aria-label` is '주차 대행'.
- Accessibility defaults are provided, and you can customize them as needed.
- _(Hover the icon to see the tooltip.)_

<A11yPropsCompareList icon={'valet'} ariaLabels={[undefined, 'Valet parking', 'Parking service']} />

```tsx
<CarmoreIcon icon={'valet'} ... /> // Uses the default ('주차 대행')
<CarmoreIcon icon={'valet'} aria-label={'Valet parking'} ... />
<CarmoreIcon icon={'valet'} aria-label={'Parking service'} ... />
```
