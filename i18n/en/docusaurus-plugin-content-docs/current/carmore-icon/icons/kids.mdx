## Size

Adjust the icon size with the `width` and `height` props.

- Pass numbers directly, or strings that include units such as 'px', 'rem', or '%'.
  - (The original aspect ratio is fixed and cannot be changed.)
- The default `width` is '1.5rem'.
- The default `height` is '1.5rem'.

<SizePropsCompareList icon={'kids'} sizes={['1.5rem', 30, '48px', '5rem']} />

```tsx
<CarmoreIcon icon={'kids'} ... /> // Uses the default ('1.5rem')
<CarmoreIcon icon={'kids'} width={30} height={30} ... />
<CarmoreIcon icon={'kids'} width={'48px'} height={'48px'} ... />
<CarmoreIcon icon={'kids'} width={'5rem'} height={'5rem'} ... />
```

## Accessibility (a11y)

We recommend setting accessibility attributes such as `role` and `aria-label`.

- The default `role` is 'img'.
- The default `aria-label` is '어린이 놀이시설'.
- Accessibility defaults are provided, and you can customize them as needed.
- _(Hover the icon to see the tooltip.)_

<A11yPropsCompareList icon={'kids'} ariaLabels={[undefined, 'Kids zone', 'Activities']} />

```tsx
<CarmoreIcon icon={'kids'} ... /> // Uses the default ('어린이 놀이시설')
<CarmoreIcon icon={'kids'} aria-label={'Kids zone'} ... />
<CarmoreIcon icon={'kids'} aria-label={'Activities'} ... />
```
