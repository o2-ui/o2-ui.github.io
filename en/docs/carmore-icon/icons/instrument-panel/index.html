InstrumentPanel


released version: 1.4.0

Usage​

import { CarmoreIcon } from '@o2-ui/carmore-icon';

// ...

  <CarmoreIcon icon={'instrument-panel'} ... />

// ...


Size​

Adjust the icon size with the width and height props.

  • Pass numbers directly, or strings that include units such as 'px', 'rem', or '%'.
    • (The original aspect ratio is fixed and cannot be changed.)
  • The default width is '1.5rem'.
  • The default height is '1.5rem'.
<CarmoreIcon icon={'instrument-panel'} ... /> // Uses the default ('1.5rem')
<CarmoreIcon icon={'instrument-panel'} width={30} height={30} ... />
<CarmoreIcon icon={'instrument-panel'} width={'48px'} height={'48px'} ... />
<CarmoreIcon icon={'instrument-panel'} width={'5rem'} height={'5rem'} ... />


Color​

Set className with a text color to change the icon color.

.text-red {
  color: red;
}

.text-orange {
  color: orange;
}

.text-green {
  color: green;
}

.text-blue {
  color: blue;
}

.text-purple {
  color: purple;
}
<CarmoreIcon icon={'instrument-panel'} className={'text-red'} ... />
<CarmoreIcon icon={'instrument-panel'} className={'text-orange'} ... />
<CarmoreIcon icon={'instrument-panel'} className={'text-green'}  ... />
<CarmoreIcon icon={'instrument-panel'} className={'text-blue'}  ... />
<CarmoreIcon icon={'instrument-panel'} className={'text-purple'}  ... />


Accessibility (a11y)​

We recommend setting accessibility attributes such as role and aria-label.

  • The default role is 'img'.
  • The default aria-label is '차량 계기판'.
  • Default accessibility props are provided, and you can customize them as needed.
  • (Hover over the icon.)
<CarmoreIcon icon={'instrument-panel'} ... /> // Uses the default ('차량 계기판')
<CarmoreIcon icon={'instrument-panel'} aria-label={'Dashboard'} ... />
<CarmoreIcon icon={'instrument-panel'} aria-label={'Control panel'} ... />
